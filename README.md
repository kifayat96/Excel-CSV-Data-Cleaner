# Excel/CSV Data Cleaner

A simple and user-friendly Windows desktop application built with Python to clean Excel and CSV files.

## Features

- Remove duplicate rows
- Remove completely empty rows
- Supports `.xlsx` and `.csv` files
- Save cleaned data as a new file
- View the number of rows removed
- No Python installation required

## Technologies Used

- Python
- Pandas
- Tkinter
- PyInstaller

## Who Is It For?

- Students and researchers
- Office workers
- Data entry professionals
- Freelancers
- Anyone working with Excel or CSV data
